# Learning Roadmap Trackers / نقشه‌های راهِ یادگیری

Two self-contained, bilingual (Persian ⇄ English) interactive learning trackers. Open any `.html` file in a browser — no install, no build, no internet required after load. Progress, language, and theme are saved automatically in your browser.

## Files

| File | What it is |
|---|---|
| `ai-pm-roadmap-tracker-v1.html` | **Project Management for the AI era** — from absolute zero (no technical/design/product background) to managing AI projects. 8 levels · 54 tasks (~26h), real AI case studies (Zillow, IBM Watson, Air Canada, GitHub Copilot…), a 9-book library with summaries, and a 14-tool toolbox. |
| `design-roadmap-tracker-v10.html` | **Product Design** — from zero to professional product designer in the AI era. 10 levels, a UI rebuild lab with 33 embedded reference images, and an AI-tool toolbox. |

## Features

- Persian (RTL) ⇄ English (LTR) toggle, fully translated content
- Dark/light theme following your system, with manual toggle
- Every video button links to an **exact, verified YouTube video** (no searches); articles link to original sources (CNBC, IEEE Spectrum, Reuters, JAMA coverage, official blogs)
- Progress tracked per task with checkboxes; resets available
- Single file per tracker — easy to share, host, or open offline

## Hosting (optional)

Enable GitHub Pages (Settings → Pages → Deploy from branch → `main`) and the trackers become shareable URLs, e.g. `https://<username>.github.io/ai-pm-roadmap/ai-pm-roadmap-tracker-v1.html`.
